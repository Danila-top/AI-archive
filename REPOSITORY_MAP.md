# Repository map

This repository contains large archival AI materials.

## Known artifacts

- AI documentation in DOCX format
- Large text export containing AI/self-awareness material
- Large Markdown/README archive

## Maintenance rule

Because the repository contains large archival files, prefer adding new companion documents over rewriting the large archive files. Preserve original source artifacts unless a deliberate archival revision is intended.

## AI-assisted workflow

Before editing any existing artifact:

1. inspect the current version;
2. verify the exact path and file type;
3. preserve the original content unless replacement is explicitly intended;
4. record what changed in a commit message.
